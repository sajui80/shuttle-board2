설치 방법 (갤럭시 기준)

  1. 위 버튼으로 APK 파일을 다운로드합니다.
  2. 다운로드 완료 알림 또는 파일함(내 파일)에서 다운로드된 apk 파일을 엽니다.
  3. “출처를 알 수 없는 앱” 관련 팝업이 뜨면 허용을 눌러줍니다. (최초 1회만)
  4. 설치를 눌러 설치를 완료합니다.
  5. 홈 화면에 생성된 퇴근셔틀2 아이콘을 실행하고, 이름을 한 번 입력합니다.
⚠️ 새 버전이 나올 때도 동일한 방법으로 다시 다운로드 후 설치하면 기존 앱 위에 업데이트됩니다. 이름과 등록 내용은 그대로 유지됩니다.
ℹ️ 기존 퇴근셔틀 앱과는 별개로 설치됩니다. 안내가 있을 때까지 기존 앱은 지우지 마시고 그대로 두세요.
🔕 이 앱은 푸시 알림을 보내지 않습니다. 알림 권한을 따로 켜실 필요가 없습니다. 16:30 미입력 명단과 17:00 마감 현황은 앱 홈 화면에서 확인하시면 됩니다.
